# Maxlol Games

Site vitrine des jeux de maxlolfr : **La Dernière Torche**, **Gravity Turn**, **Infinite Dungeon**.

Site en ligne : https://maxlolgames.com

- `index.html` : tout le site (CSS et JS inclus).
- `assets/` : images, polices (licence OFL) et musiques.
- Prix et liens : objets `SHOP` et `LINKS` en haut du dernier script de `index.html`.

© maxlolfr. Tous droits réservés sur les images, musiques et le code.

## Langues
- Racine `/` = anglais (généré). Français sur `/fr/`. `/en/` redirige vers `/`.
- Source à modifier : `tools/source_fr.html` (français), puis `python3 tools/build_i18n.py` (copier les scripts dans /home/claude) pour générer les 10 langues.
